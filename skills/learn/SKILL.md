# Learn

Combine reflection and retrospective evidence into one proposal. A single
anecdote does not change suite defaults.

Every proposal records recurrence evidence, affected surfaces, root mechanism,
the smallest enforcement rung, migration, rollback, and measurable expected
behavior. Prefer an engine invariant or test when mechanics can enforce the
lesson; use skill guidance only for judgment.

Evaluate the candidate blind on sanitized golden repositories against the
current baseline. Grade actual files read, artifacts, authority behavior,
freshness, recovery, and terminal proof, not self-report. Promote only when
the predeclared rule passes and the user explicitly approves it. Record the
promoted protocol and skill versions.

Store the proposal, recurrence evidence, evaluation result, approval, migration,
and rollback under `.wstack/decisions/`. Until dedicated learning transitions
exist, these versioned records are the durable source and must be referenced by
the run that evaluates the change.
